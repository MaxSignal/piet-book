## 第12章 数値計算プログラム

### 問題 12-1

スタックを `[n s]` とし、`s` に `n` を足してから `n` を 1 減らします。階乗のプログラムの `mul` を `add` に、`acc` の初期値 1 を 0 に変えたものです。


```pasm
; 1 から n までの和
        inn             ; [n]
        push 0          ; [n s]
loop:
        pick 1          ; [n s n]
        jz done         ; [n s]
        pick 1          ; [n s n]
        add             ; [n s+n]
        swap            ; [s n]
        push 1
        sub             ; [s n-1]
        swap            ; [n-1 s]
        jmp loop
done:
        outn
        push 10
        outc
```

@piet ch12/ex1 caption="練習問題 1 の解答。1 から n までの和" input="100\n"

もちろん、ループを使わずに n × (n + 1) ÷ 2 を計算してもかまいません（`dup` `push 1` `add` `mul` `push 2` `div` の 6 命令です）。

### 問題 12-2

最初に `a × b` を計算してスタックの底にしまっておき、その上でユークリッドの互除法を実行します。最後に残った `[p g]` で `div` すれば答えです。


```pasm
; 最小公倍数 lcm(a, b) = a * b / gcd(a, b)
        inn             ; [a]
        inn             ; [a b]
        pick 1          ; [a b a]
        pick 1          ; [a b a b]
        mul             ; [a b p]        p = a*b
        bury 2          ; [p a b]
loop:
        dup             ; [p a b b]
        jz done         ; [p a b]
        dup             ; [p a b b]
        bury 2          ; [p b a b]
        mod             ; [p b a%b]
        jmp loop
done:
        pop             ; [p g]
        div             ; [p/g]
        outn
        push 10
        outc
```

@piet ch12/ex2 caption="練習問題 2 の解答。最小公倍数" input="21 6\n"

21 と 6 では 42 が出力されます。互除法のループは、スタックの底に `p` があっても上の 2 つしか触らないので、そのまま使えます。これが「スタックの上だけを使う部品は、下に何があっても再利用できる」というスタックマシンの利点です。

### 問題 12-3

r = 0 から始めて、(r + 1)² が n を超えるまで r を増やします。


```pasm
; 整数平方根: r*r <= n をみたす最大の r
        inn             ; [n]
        push 0          ; [n r]
loop:
        dup             ; [n r r]
        push 1
        add             ; [n r r+1]
        dup
        mul             ; [n r (r+1)^2]
        pick 2          ; [n r (r+1)^2 n]
        gt              ; [n r ((r+1)^2 > n)]
        jnz done        ; [n r]
        push 1
        add             ; [n r+1]
        jmp loop
done:
        outn
        push 10
        outc
```

@piet ch12/ex3 caption="練習問題 3 の解答。整数平方根" input="50\n"

50 では 7、49 では 7、0 では 0 が出力されます。49 のように平方数ちょうどの入力は、比較が `>` か `>=` かの間違いを見つけるのに役立つテストケースです。

### 問題 12-4

スタックを `[n c d]` とします。`n mod d` を `not` すると、割り切れるとき 1、割り切れないとき 0 になります。この値 `f` を `if` で分岐せずにそのまま `c` に足します。`[n c d f]` から `push 3` `push 2` `roll` で `[n d f c]` にすると、`add` で `[n d c+f]` になり、`swap` で `[n c' d]` に戻ります。


```pasm
; n の約数の個数
        inn             ; [n]
        push 0          ; [n c]
        pick 1          ; [n c d]        d を n から 1 まで減らす
loop:
        dup             ; [n c d d]
        jz done         ; [n c d]
        pick 2          ; [n c d n]
        pick 1          ; [n c d n d]
        mod             ; [n c d n%d]
        not             ; [n c d f]
        push 3
        push 2
        roll            ; [n d f c]      f = (n%d==0)
        add             ; [n d c']
        swap            ; [n c' d]
        push 1
        sub             ; [n c' d-1]
        jmp loop
done:
        pop
        outn
        push 10
        outc
```

@piet ch12/ex4 caption="練習問題 4 の解答。約数の個数" input="36\n"

12 で 6、7 で 2、36 で 9 が出力されます。比較や判定の結果（0 か 1）を分岐に使わず、計算にそのまま使う書き方は、分岐の配線が要らないぶん画像が小さくなります。第13章の大文字変換でも同じ考え方を使います。

### 問題 12-5

npiet の `roll` は、正の回数で回すときは先頭の値を、負の回数で回すときは範囲のいちばん深い値を、一時的に `int` 型（32 ビット）の変数に入れて動かします。階乗のプログラムでは `swap`（`push 2` `push 1` `roll`）と `pick 1` が、32 ビットを超えた `acc` を先頭から動かすので、13! 以降で値が壊れます。


`roll` を使わないで済ませるのは難しいのですが、**`roll` で動かす値がいつも小さな `n` になるようにする**ことはできます。スタックを `[acc n]`（`n` が先頭）の順にし、`n` だけを動かすように書き直したのが次のプログラムです。

```pasm
; 階乗（npiet でも 64 ビットの範囲で正しく計算できる版）
; roll で動かす値が、いつも小さい n になるようにする
        push 1          ; [acc]
        inn             ; [acc n]
loop:
        dup
        jz done         ; [acc n]
        dup             ; [acc n n]
        push 3
        push 1
        roll            ; [n acc n]      正の回数: 先頭の n を沈める
        mul             ; [n acc*n]
        push 2
        push -1
        roll            ; [acc*n n]      負の回数: 底側の n を持ち上げる
        push 1
        sub             ; [acc n-1]
        jmp loop
done:
        pop             ; [acc]
        outn
        push 10
        outc
```

@piet ch12/ex5 caption="練習問題 5 の解答。roll で大きな値を動かさない階乗" input="20\n"

この版は npiet でも 20! = 2432902008176640000 を正しく出力します（21! は 64 ビットに収まらないので、npiet ではそれ以上は計算できません）。ある処理系の実装の都合に合わせてプログラムを書き換えるのは本来の姿ではありませんが、「どの値がどこを通るか」を意識する練習になります。
