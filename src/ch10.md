# 第10章 繰り返し

コンピュータの力が最も発揮されるのは、同じ処理を何度も繰り返すときです。この章では Piet で**ループ**を作る方法を学びます。

Piet のループに特別な命令は必要ありません。流れがぐるりと回って以前通ったブロックに戻ってくれば、それがループです。第8章の「白の中の時計回りの曲がり角」と、第9章の「`pointer` による分岐」を組み合わせれば、数え上げ、合計、入力の読み込みなど、ふつうの言語の `while` 文で書く処理はすべて書けます。

!!! abstract "この章で学ぶこと"
    - 時計回りの曲がり角を 4 つ使った、長方形のループの形
    - ループ入り口の作り方と、ループからの脱出
    - カウントダウン、1 から n までの数え上げ、合計
    - 番兵を使って入力の終わりまで読む方法（cat）
    - 二重ループと無限ループ

## 10.1 ループの形

### 長方形の経路

白の中で黒にぶつかると、流れは時計回りに 90 度曲がりました（第8章）。この曲がり角を 4 つ並べると、流れは長方形を一周して元の位置に戻ってきます。

```text
 ┌→ [ループ本体: 右向きの命令の帯 ] → 白 → ■
 │                                         ↓
 ↑                                         白
 │                                         ↓
 └←──────────── 白い戻りの通路 ←───────── ■
 ■
```

（■ は曲がり角を作る黒）

1. ループ本体の命令を、右向きの帯として上の段に並べる。
2. 帯の右端から白に出て、黒で下に曲がる。
3. 下の段の白い通路で左に曲がり、左端まで戻る。
4. 黒（または画像の端）で上に曲がり、ループ本体の入り口に戻る。

戻りの通路はすべて白なので、命令は実行されません。帯の先頭のブロックに白から入るので、ループの 2 周目以降も帯は同じ命令列を実行します。

### ループの入り口

ループには「最初に入るとき」と「1 周して戻ってくるとき」の 2 つの入り方があります。ここで問題になるのが、ループに入る前の準備（カウンタの初期値を積むなど）と、ループ本体の境目です。

本章のプログラムでは、次の方法を使います。ループ本体の最初のブロックを、**上の段のいちばん上の行**に置き、戻りの通路を**下から**そのブロックに入れるのです。下から入ってきた流れは DP が上を向いていますが、そのブロックの上は画像の外なので進めません。CC を切り替え、DP を時計回りに回すと右を向き、帯の続きへ進みます。こうすると、画像の端がちょうど 4 つ目の曲がり角の役目を果たしてくれます。

### ループの出口

ループから抜けるには、ループ本体の中で条件を調べ、`pointer` で流れを帯の外に出します。第9章と同じく、条件が真なら 1、偽なら 0 を積んで `pointer` を実行すれば、真のときだけ DP が下を向きます。下に出た流れは、戻りの通路を**横切って**さらに下へ滑り、停止用のブロックや後続の処理に向かいます。白い通路どうしは交差しても互いに影響しないのでした（第8章）。

## 10.2 カウントダウン

### プログラム

最初のループとして、5 から 1 までを 1 行ずつ出力するプログラムを作ります。スタックにはカウンタ n を 1 つだけ置きます。

```text
push 5                [5]       ループに入る前の準備
--- ループ本体 ---
duplicate             [n n]
out(number)           [n]       n を出力
push 10, out(char)    [n]       改行を出力
push 1, subtract      [n-1]
duplicate, not        [n-1 c]   c = (n-1 が 0 なら 1)
pointer               [n-1]     c = 1 なら下へ抜ける
--- 右へ進み、白の通路でループ本体の先頭へ戻る ---
```

@grid ch10/countdown

上の段の左端の淡赤（5 コーデル）から赤への `push` で 5 を積むのが準備です。赤のブロックがループ本体の入り口で、ここから濃シアン（10 コーデル）、淡シアン……と続き、右端の赤のブロック（`pointer` の到着先）で終わります。

### 1 周目と 2 周目

トレースを最初から見てみましょう。

@trace ch10/countdown steps=24

ステップ 1〜10 が 1 周目です。ステップ 10 の `pointer` では 0 が取り出されるので DP は右のままで、流れは右の白に出ます。「白の中で進めない」という行が 3 つ続くのは、白い通路の 3 つの曲がり角です。右端の黒で下に、下の段の黒で左に、左端の黒で上に曲がり、ステップ 11 で入り口の赤のブロックに下から入ります。

赤のブロックの上は画像の外なので、CC を切り替えても進めず、DP が時計回りに回って右を向きます。そしてステップ 12 から 2 周目の `duplicate` が始まります。1 周目とは違って `push 5` は実行されていないことに注目してください。入り口を準備の命令の**後ろ**に置いたことで、準備は一度だけ実行されます。

### 脱出

n − 1 が 0 になると、`not` の結果が 1 になり、`pointer` で DP が下を向きます。到着先の赤のブロックから下の白に出た流れは、戻りの通路の行を横切ってまっすぐ下へ滑り、3 コーデル幅の淡青のブロックに上から入ります。

この淡青のブロックは、周りを黒に囲まれた停止用のブロックです。これまでの停止用ブロックとは違い、白を通って入るので命令は実行されません。白から入るブロックで停止させるには、「入ってきたコーデルが、どの方向の出口としても選ばれない」ことが必要です。淡青のブロックは横に 3 コーデル並んでいて、真ん中のコーデルから入ります。上向きの出口は上の辺の左端か右端（CC で決まる）なので、真ん中のコーデルは選ばれません。そして左端と右端の上には黒が置いてあります。こうして 8 回の試行がすべて失敗し、プログラムは停止します。

## 10.3 終わらないループ

脱出のための分岐を取り除くと、永遠に止まらないプログラムになります。次のプログラムは 1 から順に数を出力し続けます。

@piet ch10/forever caption="1, 2, 3, … と数え上げ続ける（停止しない）"

```text
push 1                 [1]
--- ループ本体 ---
duplicate, out(number) [n]
push 10, out(char)     [n]
push 1, add            [n+1]
```

このプログラムでは、戻りの通路の左端に画像の端ではなく黒を置いて上に曲げ、2 列目にある入り口の赤のブロックに下から入っています。

終わらないプログラムを実行するときは、処理系の実行ステップ数の上限を使うと便利です。npiet なら `-e` オプション、piet.py なら `-e` オプションで上限を指定できます。

```sh
$ npiet -q -e 100 forever.png
```

Piet スタジオでは「再生」で実行し、止めたいところで停止ボタンを押します。ステップ実行で 1 周ずつ進め、スタックの値が増えていく様子を眺めてみましょう。

## 10.4 入力の終わりまで読む ― cat

### 番兵

入力をそのまま出力するプログラムを、Unix のコマンドにならって cat と呼びます。cat を作るには「入力が終わったこと」を検出する必要があります。

第7章で見たとおり、入力が尽きたときの `in(char)` は無視され、スタックには何も積まれません。そこで、読む前に目印となる値（**番兵**、sentinel）を積んでおきます。

- 文字が読めた場合: スタックは `[番兵 c]` になる。
- 入力が尽きていた場合: スタックは `[番兵]` のまま。

番兵には 0 を使います。文字コードが 0 の文字（NUL）はふつうのテキストには現れないので、「先頭が 0 なら入力の終わり」と判定できます。

### プログラム

```text
--- ループ本体 ---
push 1, not        [0]         番兵 0 を積む
in(char)           [0 c] または [0]
duplicate, not     [0 c 0] または [0 1]
pointer            [0 c]  … 0 なら右へ（続行）
                   [0]    … 1 なら下へ（終了）
out(char)          [0]         読んだ文字を出力
pop                []          番兵を捨てる
--- 白の通路でループ本体の先頭へ戻る ---
```

@piet ch10/cat caption="入力をそのまま出力する cat" input="Hello, Piet!\nsecond line\n"

@grid ch10/cat

このループには準備の命令がありません。ループ本体の先頭の `push 1` を実行するには、その出発側のブロックが 1 コーデルでなければならず、それはプログラムの左上の淡赤のコーデルそのものです。そこで、戻りの通路を左上のコーデルの真下まで延ばし、画像の左端で上に曲げて、プログラムの開始位置に下から戻ってくるようにしています。開始位置に戻るループは、プログラム全体が 1 つのループになっている形です。

入力が尽きると、次の周の `pointer` で下へ抜けて停止します（入力が空なら 1 周目で抜けます）。入力が `Hi` のときのトレースは次のとおりです。

@trace ch10/cat input="Hi"

!!! note "メモ"
    npiet の `in(char)` はバイト単位で読み、本書の piet.py は Unicode の文字単位で読みます。cat の場合はどちらも読んだものをそのまま書き出すので、日本語を含むテキストでも結果は同じになります。

## 10.5 pasm でループを書く

### ジャンプとラベル

ここまでのループは手で配置しました。ループの中に分岐が入ったり、ループが入れ子になったりすると、手で配置するのは大変です。そこで pasm を使います。pasm では、ループを次のようにラベルとジャンプで書けます。

| 書き方 | 意味 |
|---|---|
| `loop:` | ラベル（ジャンプ先）を定義する |
| `jmp loop` | 無条件で `loop` へジャンプする |
| `jz done` | 先頭を取り出し、0 なら `done` へジャンプする |
| `jnz loop` | 先頭を取り出し、0 でなければ `loop` へジャンプする |

pasm はラベルごとに命令の行を作り、ジャンプを白い通路の配線に変換します。どのジャンプも、10.1 節で見た「右へ出て、下へ曲がり、左へ戻り、上へ曲がり、右から行に入る」という時計回りの経路で実現されています。

### 1 から n までの和

入力した n について、1 + 2 + … + n を求めるプログラムです。スタックには n（残りの数）と s（途中の和）の 2 つを置きます。

```pasm
; 1 から n までの和を求める
  inn            ; [n]
  push 0         ; [n s]
loop:
  pick 1         ; [n s n]
  jz done        ; [n s]       n が 0 なら終わり
  pick 1         ; [n s n]
  add            ; [n s+n]
  swap           ; [s n]
  push 1
  sub            ; [s n-1]
  swap           ; [n-1 s]
  jmp loop
done:
  outn           ; 和を出力
  push 10
  outc
```

`pick 1` は「上から 2 番目の値を複製して積む」、`swap` は「上 2 つを入れ替える」pasm のマクロです。どちらも `roll` を使った命令列に展開されます（第11章）。各行の右側のコメントは、その行を実行した後のスタックです。ループを書くときは、このように**ループの先頭でのスタックの形**を決め、1 周したときに同じ形に戻ることを確かめながら書くのがこつです。この例では、ループの先頭で常に `[n s]` の形になっています。

@piet ch10/sum caption="1 から n までの和（入力 10 → 出力 55）" input="10\n"

入力が 0 なら、最初の `jz` でただちに `done` へジャンプして 0 を出力します。

### 1 から n まで数え上げる

カウントダウンの逆に、1 から n まで数え上げることもできます。今度はカウンタ i と上限 n の 2 つを置き、i > n になったら抜けます。

```pasm
; 1 から n までを 1 行に 1 つずつ出力する
  inn            ; [n]
  push 1         ; [n i]
loop:
  dup            ; [n i i]
  pick 2         ; [n i i n]
  gt             ; [n i i>n]
  jnz end
  dup
  outn
  push 10
  outc
  push 1
  add            ; [n i+1]
  jmp loop
end:
  halt
```

## 10.6 二重ループ

ループの中にループを入れることもできます。n 段の三角形を `*` で描くプログラムを作ってみましょう。

```text
*
**
***
****
```

外側のループで段 i を 1 から n まで進め、内側のループで `*` を i 個出力します。

```pasm
; n 段の * の三角形（二重ループ）
  inn            ; [n]
  push 1         ; [n i]      i 段目（1 から）
row:
  dup            ; [n i i]
  pick 2         ; [n i i n]
  gt             ; [n i i>n]
  jnz end        ; [n i]
  dup            ; [n i k]    この段で残り k 個
star:
  dup            ; [n i k k]
  jz eol         ; [n i k]
  push 42        ; '*'
  outc
  push 1
  sub            ; [n i k-1]
  jmp star
eol:
  pop            ; [n i]
  push 10
  outc
  push 1
  add            ; [n i+1]
  jmp row
end:
  halt
```

@piet ch10/triangle caption="* の三角形を描く二重ループ（入力 4）" input="4\n"

スタックの形に注目してください。外側のループの先頭では `[n i]`、内側のループの先頭では `[n i k]` です。内側のループを抜けたら（`eol`）、k を `pop` で捨てて外側の形 `[n i]` に戻しています。入れ子のループでは、内側のループが外側のループの値を壊さないように、スタックの上に自分の値を積んで使い、抜けるときに片付けるのが基本です。

!!! column "コラム: 手で描くか、生成するか"
    pasm で生成したループは、大きく、白い通路が目立つ画像になります。手で描いたカウントダウンは 27 × 6 コーデルでしたが、同程度の処理を pasm で書くと 45 × 27 コーデル前後になります。生成された画像は正しさが保証しやすく、手で描いた画像は小さく美しくできます。実際の Piet プログラミングでは、まず pasm のような道具で動くものを作り、それを手で小さく描き直す、という進め方もよく使われます。第15章では、手で描くときのデザインの考え方を扱います。

## まとめ

- 白の中の時計回りの曲がり角を 4 つ使うと、流れが長方形を一周するループになる。
- ループ本体の先頭ブロックに、戻りの通路を下から入れる。画像の上端が最後の曲がり角になり、準備の命令は一度だけ実行される。
- ループからの脱出は、条件を 0/1 にして `pointer` で帯の外へ流れを出す。脱出路は戻りの通路を横切ってよい。
- 入力の終わりは、読む前に番兵を積んでおき、読み込み後の先頭が番兵かどうかで判定する。
- pasm ではラベルと `jmp` `jz` `jnz` でループを書ける。ループの先頭でのスタックの形を決め、1 周で同じ形に戻るように書く。

2. カウントダウンを、1 行に 1 つではなく `5 4 3 2 1 ` のように空白区切りで出力するように変更してください（空白は 32）。
3. 入力した n について、n の階乗を求めるプログラムを pasm で書いてください。
4. 入力された文字の個数を数えて出力するプログラムを pasm で書いてください（ヒント: cat と同じく番兵を使う）。
5. 整数 n を読み、`n x 1 = n` から `n x 9 = 9n` までの 9 行（n が 7 なら `7 x 1 = 7` から `7 x 9 = 63`）を出力するプログラムを pasm で書いてください。
