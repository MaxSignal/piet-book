## 第11章 スタックを使いこなす

### 問題 11-1

対象は上から 4 つの `2 3 4 5` です。

- `push 4, push 1, roll`: 先頭の 5 が 4 つ目の位置に沈み、`[1 5 2 3 4]` になります。
- `push 4, push 3, roll`: 沈める操作を 3 回行います。2 3 4 5 → 5 2 3 4 → 4 5 2 3 → 3 4 5 2 となり、`[1 3 4 5 2]` です。これは逆向きに 1 回（一番下の 2 を先頭に持ち上げる）回したのと同じです。

### 問題 11-2

`duplicate` で `[a b b]` にしてから、先頭の b を深さ 3 の位置に沈めます（-rot と同じ `push 3, push 1, roll`）。

```text
[a b]  duplicate          →  [a b b]
       push 3, push 1, roll  →  [b a b]
```

### 問題 11-3

-rot で `[c a b]` にしてから swap すると `[c b a]` になります。

```text
[a b c]  push 3, push 1, roll  →  [c a b]
         push 2, push 1, roll  →  [c b a]
```

@piet ch11/ex3 caption="[1 2 3] を [3 2 1] にして出力する（出力 123）"

rot と swap の組み合わせ（`[b c a]` → …）では逆順にならないことも確かめてみてください。

### 問題 11-4

a、b、c を底に置いたまま、pick で必要な値を複製して計算します。途中結果 t を先頭に置くと、a・b・c の深さが 1 つずつ深くなることに注意します。

```pasm
  inn
  inn
  inn            ; [a b c]
  pick 2         ; [a b c a]
  pick 2         ; [a b c a b]
  mul            ; [a b c ab]
  pick 2         ; [a b c ab b]
  pick 2         ; [a b c ab b c]
  mul
  add            ; [a b c ab+bc]
  pick 1         ; [a b c t c]
  pick 4         ; [a b c t c a]
  mul
  add            ; [a b c ab+bc+ca]
  outn
  push 10
  outc
```

@piet ch11/ex4 caption="ab + bc + ca（入力 2, 3, 4 → 出力 26）" input="2\n3\n4\n"

### 問題 11-5

深さ d のロールを 1 回行うと、対象の d 個の値は 1 つずつ位置がずれ、先頭の値が一番下へ移ります。これを d 回繰り返すと、すべての値がちょうど一周して元の位置に戻ります。したがって回数 d（一般に d の倍数）のロールはスタックを変えません。
