# 付録F 用語集

本書で使う主な用語を五十音順（英字の略語は末尾）にまとめます。括弧内は対応する英語、→ は主に説明している章です。

## F.1 用語

**アセンブラ**（assembler）
: 命令の列とラベル・ジャンプを書いたテキストから、Piet の画像を生成するプログラム。本書付属の pasm.py がこれにあたる。→ 第17章

**色ブロック**（colour block）
: 同じ色のコーデルが上下左右につながったかたまり。斜めに接しているだけではつながらない。単にブロックともいう。→ 第3章

**インタプリタ**（interpreter）
: プログラムを読み込んで直接実行するソフトウェア。npiet や piet.py。→ 第2章、第16章

**大きさ**（ブロックの）
: 色ブロックに含まれるコーデルの数。`push` 命令はこの値を積む。→ 第3章、第6章

**規定外の色**
: Piet の 20 色以外の色。扱いは実装に依存し、npiet と piet.py は既定で白として扱う。→ 第3章、付録C

**黒**（black）
: 実行が進めない「壁」となる色。黒いコーデルや画像の外に進もうとすると、CC の切り替えや DP の回転が起こる。→ 第5章

**コーデル**（codel）
: Piet のプログラムを構成する最小単位のマス。画像の 1 ピクセル、または拡大された正方形のかたまりに相当する。→ 第3章

**コーデルサイズ**（codel size）
: 1 コーデルを何ピクセル四方で描くか。npiet では `-cs` で指定する。→ 第2章

**コーデルチューザ**（Codel Chooser, CC）
: 出口のコーデルを、DP の向きに対して左寄りから選ぶか右寄りから選ぶかを決める状態。初期値は左。→ 第5章

**コンパイラ**（compiler）
: あるプログラムを別の形式のプログラムに変換するソフトウェア。本書では、小さな言語から Piet の画像を作るコンパイラを作る。→ 第18章

**再試行**
: 進んだ先が黒か画像の外だったときに、CC の切り替えと DP の時計回りの回転を交互に行って出直すこと。8 回失敗すると終了する。→ 第5章

**色相**（hue）
: 赤・黄・緑・シアン・青・マゼンタの 6 段階の色合い。この順に循環する。→ 第3章

**色相の差**（hue change）
: 移動元の色から移動先の色まで、色相の環を一方向に何段階進んだか（0〜5）。明度の差と合わせて命令を決める。→ 第4章

**終了**（termination）
: いまいるブロックから 8 回続けてどこへも進めなかったとき、プログラムは終了する。Piet に停止命令はない。→ 第5章

**白**（white）
: 実行が命令なしに通り抜ける「通路」となる色。白い領域に入ると DP の向きにまっすぐ滑る。→ 第8章

**スタック**（stack）
: Piet のすべてのデータを置く場所。整数を積み重ね、最後に積んだもの（先頭）から取り出す。本書では `[3 5 7]` のように、左を底、右を先頭として書く。→ 第6章

**滑る**（slide）
: 白い領域に入ったインタプリタが、DP の向きに白いコーデルを通り抜けて進むこと。→ 第8章

**先頭**（top）
: スタックで最後に積まれた値。次に取り出される値。トップともいう。

**テキスト記法**
: 本書で使う、1 文字 = 1 コーデルで Piet のプログラムを表す書き方。淡い色は小文字、通常の色は大文字、濃い色は数字、白は `.`、黒は `#`。→ 第3章、付録B

**出口のコーデル**
: 色ブロックから次のブロックへ移るときに通るコーデル。DP の向きに最も遠い辺のうち、CC の向きに最も遠いもの。→ 第5章

**トレース**（trace）
: プログラムの実行を 1 ステップずつ記録したもの。npiet では `-t`、piet.py では `run -t` で表示する。→ 第2章、第19章

**トレース画像**
: 実行の経路を画像の上に描いたもの。npiet の `-tpic` で作れる。→ 第2章

**難解プログラミング言語**（esoteric programming language, esolang）
: 実用ではなく、遊びや実験、計算の本質を考えることを目的に作られたプログラミング言語。Piet はその一つ。→ 第1章

**方向ポインタ**（Direction Pointer, DP）
: インタプリタが進もうとしている向き。右・下・左・上のいずれかで、初期値は右。→ 第5章

**明度**（lightness）
: 淡い・通常・濃いの 3 段階の明るさ。この順に循環する（濃いの次は淡い）。→ 第3章

**明度の差**（lightness change）
: 移動元の色から移動先の色まで、明度の環を一方向に何段階進んだか（0〜2）。→ 第4章

**命令表**
: 色相の差と明度の差の組み合わせと、17 個の命令の対応表。→ 第4章、付録A

**融合**
: 同じ色のブロックどうしが上下左右に接して、一つのブロックになってしまうこと。意図しない融合はよくあるバグの原因になる。→ 第3章、第19章

**わな**
: 本書での呼び名で、入ったら二度と出られないように黒と画像の端で囲んだ色ブロック。プログラムを終了させるために使う。入り口のコーデルが出口に選ばれない形（L 字形など）にする必要がある。→ 第5章

## F.2 略語・名称

**CC**
: コーデルチューザ（Codel Chooser）。

**DP**
: 方向ポインタ（Direction Pointer）。

**npiet**
: Erik Schoenfelder による C 製の Piet インタプリタ。本書ではバージョン 1.3h を使う。→ 第2章

**npiet-foogol**
: npiet に同梱されている、ALGOL 風の小さな言語 foogol から Piet の画像を作るコンパイラ。→ 第18章

**pasm.py**
: 本書付属の Piet アセンブラ。→ 第17章

**piet.py**
: 本書付属の Python 製 Piet インタプリタ。→ 第16章

**PPM**
: 画素の値を並べただけの単純な画像形式。npiet はライブラリなしでもこの形式を読める。→ 第2章
