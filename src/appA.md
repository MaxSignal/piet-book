## A.2 命令の一覧

| 命令 | 色相の差 | 明度の差 | スタックの変化 | 動作 | 失敗時（仕様） |
|---|---|---|---|---|---|
| `push` | 0 | 1 | `[…]` → `[… n]` | 移動元の色ブロックの大きさ n を積む | 失敗しない |
| `pop` | 0 | 2 | `[… a]` → `[…]` | 先頭を捨てる | 空なら無視 |
| `add` | 1 | 0 | `[… a b]` → `[… a+b]` | 和 | 値が 2 つ未満なら無視 |
| `subtract` | 1 | 1 | `[… a b]` → `[… a−b]` | 差（2 番目 − 先頭） | 同上 |
| `multiply` | 1 | 2 | `[… a b]` → `[… a×b]` | 積 | 同上 |
| `divide` | 2 | 0 | `[… a b]` → `[… a÷b]` | 整数の商（2 番目 ÷ 先頭） | 0 による除算は実装依存（無視を推奨） |
| `mod` | 2 | 1 | `[… a b]` → `[… a mod b]` | 余り。結果は除数 b と同じ符号 | 同上 |
| `not` | 2 | 2 | `[… a]` → `[… 0 または 1]` | a が 0 なら 1、それ以外なら 0 | 空なら無視 |
| `greater` | 3 | 0 | `[… a b]` → `[… 0 または 1]` | a > b なら 1、そうでなければ 0 | 値が 2 つ未満なら無視 |
| `pointer` | 3 | 1 | `[… n]` → `[…]` | DP を時計回りに n 回回す（負なら反時計回り） | 空なら無視 |
| `switch` | 3 | 2 | `[… n]` → `[…]` | CC を n 回切り替える（負なら絶対値の回数） | 空なら無視 |
| `duplicate` | 4 | 0 | `[… a]` → `[… a a]` | 先頭を複製する | 空なら無視 |
| `roll` | 4 | 1 | `[… x₁ … x_d d n]` → 回転後 | 深さ d の範囲を n 回回転させる（下記） | d が負なら無視。深さが大きすぎる場合は実装依存（無視を推奨） |
| `in(number)` | 4 | 2 | `[…]` → `[… v]` | 数を読み込んで積む | 入力がない・数でないなら無視 |
| `in(char)` | 5 | 0 | `[…]` → `[… c]` | 文字を読み込み、文字コードを積む | 入力がないなら無視 |
| `out(number)` | 5 | 1 | `[… a]` → `[…]` | 先頭を数として出力する | 空なら無視 |
| `out(char)` | 5 | 2 | `[… a]` → `[…]` | 先頭を文字コードとみなして文字を出力する | 空なら無視 |

### roll の詳細

`roll` は、まず先頭の値 n（回転の回数）と 2 番目の値 d（深さ）を取り出します。次に、残ったスタックの上から d 個の値を対象に、「先頭の値を深さ d の位置に埋め、それより上の値を 1 つずつ持ち上げる」操作を n 回行います。n が負なら逆向きに |n| 回回転させます。

| 実行前 | 実行後 | 説明 |
|---|---|---|
| `[1 2 3 3 1]` | `[3 1 2]` | 深さ 3 で 1 回。先頭の 3 が 3 番目に沈む |
| `[1 2 3 3 2]` | `[2 3 1]` | 深さ 3 で 2 回 |
| `[1 2 3 3 -1]` | `[2 3 1]` | 深さ 3 で −1 回（逆向き）。3 番目の 1 が先頭に浮かぶ |
| `[1 2 2 1]` | `[2 1]` | 深さ 2 で 1 回。上の 2 つを入れ替える（swap） |

### 二項演算の順序

`subtract`、`divide`、`mod`、`greater` では、**先に積んだ値（2 番目）が左、あとから積んだ値（先頭）が右**です。`[7 3]` に対して `subtract` は 7 − 3、`divide` は 7 ÷ 3、`greater` は 7 > 3 を計算します。

## A.3 実行の流れの規則

| 項目 | 規則 |
|---|---|
| 開始 | 左上のコーデルを含む色ブロックから。DP は右、CC は左 |
| 出口の選択 | DP の向きに最も遠い辺のうち、CC の向き（DP を向いたときの左手・右手）に最も遠いコーデル |
| 移動 | 出口から DP の向きに 1 コーデル進む |
| 色ブロックへの移動 | 色の変化に応じた命令を実行する |
| 黒・画像の外 | 進めない。CC の切り替えと DP の時計回りの回転を交互に行って再試行する（最初は CC） |
| 終了 | 8 回続けて進めなければ終了 |
| 白への移動 | DP の向きに白い領域を滑る。命令は実行しない（第8章） |
| 白の中で進めない | CC を切り替え、DP を時計回りに回して滑り直す。同じ経路をたどり始めたら終了（第8章） |
| 実行できない命令 | 無視して次へ進む |

## A.4 DP と CC の出口対応表

| DP | CC | 選ばれるコーデル |
|---|---|---|
| 右 | 左 | 右端の列の最も上 |
| 右 | 右 | 右端の列の最も下 |
| 下 | 左 | 下端の行の最も右 |
| 下 | 右 | 下端の行の最も左 |
| 左 | 左 | 左端の列の最も下 |
| 左 | 右 | 左端の列の最も上 |
| 上 | 左 | 上端の行の最も左 |
| 上 | 右 | 上端の行の最も右 |

## A.5 よく使う命令の組み合わせ

| 目的 | 命令の列 | スタックの変化 |
|---|---|---|
| 0 を積む | `push 1`, `not` | `[…]` → `[… 0]` |
| 上 2 つを交換（swap） | `push 2`, `push 1`, `roll` | `[… a b]` → `[… b a]` |
| 2 番目を複製（over） | `push 2`, `push 1`, `roll`, `duplicate`, `push 3`, `push 1`, `roll` | `[… a b]` → `[… a b a]` |
| 2 乗 | `duplicate`, `multiply` | `[… a]` → `[… a²]` |
| 符号反転 | `push 1`, `not`, `push 2`, `push 1`, `roll`, `subtract` | `[… a]` → `[… −a]` |
| 0 でなければ 1 | `not`, `not` | `[… a]` → `[… 0 または 1]` |
| a ≤ b | `greater`, `not` | `[… a b]` → `[… 0 または 1]` |

ここで `push n` は「大きさ n のブロックから `push` する」ことを表します。これらの技法は第6章、第9章、第11章で詳しく説明します。
