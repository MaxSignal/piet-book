# はじめに

Piet（ピート）は、絵がそのままプログラムになるプログラミング言語です。ソースコードはテキストファイルではなく画像で、色のついたマス目（コーデル）の並びが命令を表します。隣り合う色の「違い」が命令を決め、色の塊の「大きさ」が数を表し、黒い壁と白い通路が処理の流れを導きます。

このような言語は、実用よりも発想の面白さを追求した「難解プログラミング言語（esoteric programming language）」の一つに数えられます。しかし Piet は、ただの冗談では終わりません。スタックマシンとしての計算モデルは素直で、分岐も繰り返しも書けますし、理論上はどんな計算でも表現できます。そのうえ、「二次元の平面に命令を配置する」という制約は、普段のプログラミングでは意識しない多くのこと、たとえば命令の並び順と配置、制御の流れの形、処理系がプログラムをどう読むかを、具体的な手触りとともに考えさせてくれます。

本書は、Piet をはじめて学ぶ人のための入門書です。最初のページで小さなプログラムを動かすところから始め、言語の仕組みを一つずつ確かめながら、最後には Piet のインタプリタ・アセンブラ・コンパイラを自分で作るところまで進みます。

## 本書の対象読者

本書は、何らかのプログラミング言語で簡単なプログラムを書いた経験がある人を想定しています。変数、条件分岐、繰り返しといった基本的な考え方を知っていれば十分です。スタックや逆ポーランド記法になじみがなくても、本文で一から説明します。

本書付属のツールはすべて Python で書かれており、第IV部では Python で処理系を作ります。Python の文法を細かく知らなくても読めるように説明しますが、自分で手を動かすなら Python 3 の実行環境があると便利です。

## 本書の構成

本書は 4 つの部と付録からなります。

- **第I部 Piet の基本**（第1章〜第5章）: 最初のプログラムを動かし、開発環境を整え、色とコーデル、命令の決まり方、実行の流れ（DP と CC）を学びます。ここまで読めば、どんな Piet のプログラムでも「どう動くか」を自分で追えるようになります。
- **第II部 プログラミングの基礎**（第6章〜第11章）: スタックと算術、入出力、白と黒による配線、条件分岐、繰り返し、スタック操作の技法を学びます。ここまでで、普通の言語で書く小さなプログラムを Piet で描けるようになります。
- **第III部 実践プログラミング**（第12章〜第15章）: 数値計算、文字列処理、FizzBuzz などの総合演習を通して、仕様から設計し、描き、テストする流れを身につけます。最後に、動くだけでなく美しい Piet の描き方を考えます。
- **第IV部 処理系を作る**（第16章〜第20章）: Piet のインタプリタ、アセンブラ、小さな言語からのコンパイラを Python で作り、デバッグとテストの技法、Piet を取り巻く処理系やコミュニティを紹介します。
- **付録**: 命令早見表、色一覧とテキスト記法、仕様の曖昧な点と処理系ごとの違い、練習問題の解答、参考文献、用語集、付属ツールのソースコード、Piet の派生言語と関連言語、Piet イディオム集、数と文字の作り方表。

第I部と第II部は順番に読むことをおすすめします。第III部の各章と第IV部は、興味のあるところから読んでもかまいません。

### 図はそのまま動かせる

本書の図に載っている Piet のプログラムは、ブラウザの中でそのまま実行できます。図の下にあるボタンの働きは次のとおりです。

| ボタン | 働き |
|---|---|
| 実行 | プログラムを最後まで（停止するまで）実行し、出力を表示します |
| 再生 | 1 ステップずつ、動きが目で追える速さで実行します。もう一度押すと一時停止します |
| 1 ステップ | 色ブロックから次の色ブロックへの移動を 1 回だけ行います |
| リセット | 最初の状態に戻します |

実行中は、いま実行しているブロックが白と黒の枠で囲まれ、現在位置に DP（進む向き）を示す三角形が表示されます。図の下の欄には、ステップ数、DP と CC の状態、直前に実行した命令、スタックの中身が表示されます。入力を読むプログラムには「入力」欄があり、内容を書き換えて試すことができます。

各章の扉にある色の帯も、その章の番号を出力する Piet のプログラムです。「実行する」を押すと確かめられます。

### 手元で描いて動かす: Piet スタジオ

自分でプログラムを描いて試すための道具として、本書には Python 製のデスクトップアプリ **Piet スタジオ** が付属しています。Python に標準で付いている tkinter だけで動くので、Python が入っていればすぐに使えます。パレットで色を選ぶと、各色に「その色へ移ったときに実行される命令」が表示されるので、命令を選ぶ感覚で絵を描けます。描いたプログラムはその場で実行・1 ステップ実行でき、スタックやトレースも確認できます。使い方は第2章で、ソースコードは付録G で紹介します。ツールとサンプルプログラムは、本書の原稿や PDF とともに GitHub（https://github.com/MaxSignal/piet-book）で公開しています（CC0 1.0）。

### 検証について

本文の Piet プログラムはすべて、本書のために用意したインタプリタ（第16章で解説する piet.py）と、広く使われている npiet 1.3h の両方で実行し、出力が一致すること、そして期待どおりの出力になることを確認しています。npiet と仕様のあいだにはいくつか違いがあります（付録C）。本書のプログラムは、その違いに左右されないように書いています。違いそのものを見せるための例だけは、そのことを本文に明記しています。

### 表記

- 色の名前は「淡赤・赤・濃赤」のように、明度（淡い・通常・濃い）と色相を組み合わせて呼びます。全 20 色の一覧は付録B にあります。
- 命令の名前は `push` や `out(char)` のように、仕様に合わせて英語で書きます。
- スタックの中身は `[3 5 7]` のように書き、右端を先頭（トップ）とします。この例では 7 が先頭です。
- 本文で Piet のプログラムを文字で表すときは、1 文字を 1 コーデルとするテキスト記法を使います（第3章、付録B）。
