### 問題 10-3

1 から n までの和のプログラム（10.5 節）の `add` を `multiply` に、和の初期値 0 を積の初期値 1 に変えれば階乗になります。

```pasm
  inn            ; [n]
  push 1         ; [n f]
loop:
  pick 1         ; [n f n]
  jz done        ; [n f]
  pick 1         ; [n f n]
  mul            ; [n f*n]
  swap
  push 1
  sub
  swap           ; [n-1 f*n]
  jmp loop
done:
  outn
  push 10
  outc
```

### 問題 10-4

数えた個数をスタックの底に置き、その上で cat と同じく番兵 0 を積んでから `in(char)` します。読めた場合は読んだ文字と番兵を捨てて個数に 1 を足し、読めなかった場合は番兵を捨てて個数を出力します。

```pasm
  push 0         ; [count]
loop:
  push 0         ; [count 0]      番兵
  inc            ; [count 0 c] または [count 0]
  dup
  not
  jnz done
  pop
  pop            ; [count]
  push 1
  add            ; [count+1]
  jmp loop
done:
  pop            ; [count]
  outn
  push 10
  outc
```

### 問題 10-5

`[n k]` をループの形とし、k を 1 から 9 まで進めます。`pick 1` で n を、`dup` で k を複製して出力し、`pick 1` を 2 回使って `[n k n k]` を作ってから掛け算します。

```pasm
  inn            ; [n]
  push 1         ; [n k]
loop:
  dup
  push 9
  gt             ; [n k k>9]
  jnz end
  pick 1
  outn           ; n
  prints " x "
  dup
  outn           ; k
  prints " = "
  pick 1
  pick 1
  mul
  outn           ; n*k
  push 10
  outc
  push 1
  add
  jmp loop
end:
  halt
```
