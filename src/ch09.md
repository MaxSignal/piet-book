# 第9章 比較と条件分岐

ここまでのプログラムは、色の帯に沿って一本道で進むものばかりでした。この章では、計算の結果によって進む道を変える**条件分岐**を学びます。

Piet には `if` 文も比較演算子付きのジャンプ命令もありません。代わりにあるのは、DP や CC という「進む向きを決める状態」を書き換える命令です。値によって DP の向きを変えれば、流れはその向きへ進んでいきます。これが Piet の条件分岐のすべてです。

!!! abstract "この章で学ぶこと"
    - 真偽値を作る `not` と `greater`
    - DP を回す `pointer` と、CC を切り替える `switch`
    - `pointer` を使った二方向の分岐と、分岐した流れの合流
    - `switch` とブロックの形を使った分岐
    - 三方向以上の分岐を pasm で書く方法

## 9.1 真偽値を作る

### Piet の真偽値

Piet に真偽値の型はありません。本書では C 言語などと同じく、**0 を偽、それ以外を真**とみなします。ただし、分岐に使うときは真を 1 にそろえておくと便利です。以下の 2 つの命令は、どちらも結果として 0 か 1 を積みます。

### not

`not` は、先頭の値を取り出し、それが 0 なら 1 を、0 以外なら 0 を積みます。色相の変化 2、明度の変化 2 の命令です。

@piet ch09/not caption="7 に not を適用すると 0、それにもう一度 not を適用すると 1"

@trace ch09/not

このプログラムは 7 を積んで `not` し（結果 0）、`duplicate` して一方を出力したあと、もう一方に `not` を適用して 1 を出力します。出力は `01` です。

`not` を 2 回続けると、「0 なら 0、0 以外なら 1」という変換になります。任意の整数を 0 と 1 にそろえるのに便利な組み合わせです。また、第6章で見たように、1 に `not` を適用すると 0 を作れます。

### greater

`greater` は、上から 2 つの値を取り出し、**2 番目の値が先頭の値より大きければ 1、そうでなければ 0** を積みます。色相の変化 3、明度の変化 0 の命令です。引き算と同じく、先に積んだほうが左辺になると覚えてください。

@piet ch09/greater caption="5 > 3 は 1、3 > 5 は 0。出力は 10"

`greater` しかないので、そのほかの比較は組み合わせて作ります。

| 比較 | 作り方 |
|---|---|
| a > b | a、b の順に積んで `greater` |
| a < b | b、a の順に積んで `greater`（または a、b を積んで入れ替えてから `greater`） |
| a ≤ b | a > b を作って `not` |
| a ≥ b | a < b を作って `not` |
| a = b | `subtract` で差を作って `not`（差が 0 なら 1） |
| a ≠ b | `subtract` で差を作って `not` `not` |

## 9.2 流れの向きを変える命令

### pointer

`pointer` は、先頭の値 n を取り出し、**DP を時計回りに n 段階回します**。n が負なら反時計回りに回します。色相の変化 3、明度の変化 1 の命令です。DP は 4 方向しかないので、4 段階回すと元に戻ります。

| n | DP が右のとき | DP の動き |
|---|---|---|
| 0 | 右 | 変わらない |
| 1 | 下 | 時計回りに 90 度 |
| 2 | 左 | 180 度（向きが逆になる） |
| 3 | 上 | 時計回りに 270 度 = 反時計回りに 90 度 |
| −1 | 上 | 反時計回りに 90 度 |

`pointer` が実行されるのは、ブロック A からブロック B へ移ったときです。DP が変わるのはその後なので、B からの出口は**新しい DP** で決まります。つまり、分岐の結果どちらへ進むかは、B のどの辺から出ていくかの違いとして現れます。

### switch

`switch` は、先頭の値 n を取り出し、**CC を n 回切り替えます**。CC は左右の 2 状態しかないので、n が偶数なら変わらず、奇数なら反対になります。仕様では n が負のときは絶対値の回数だけ切り替えると定められています。色相の変化 3、明度の変化 2 の命令です。

CC は、出口の辺の上でどのコーデルを選ぶかを決める状態でした（第5章）。したがって `switch` で流れが変わるのは、**DP の方向の辺に複数のコーデルがあり、CC によって選ばれる出口が変わる形のブロック**から出るときだけです。

!!! warning "注意"
    npiet の `switch` は、n が負のときに CC を切り替えません（仕様では |n| 回切り替える）。また `pointer` と `switch` に限らず、負の値が絡む分岐は処理系による差が出やすいところです。分岐に使う値は 0 以上にそろえておくのが安全です（付録C）。

## 9.3 pointer による二方向の分岐

### 基本の形

`pointer` を使った分岐の基本は次のとおりです。

1. 条件を計算し、真なら 1、偽なら 0 をスタックに積む。
2. `pointer` を実行する。DP が右なら、真のときは下へ、偽のときは右へ向きが変わる。
3. `pointer` の到着先のブロック（1 コーデル）から、右と下の 2 方向に別々の道を用意しておく。

```text
   … → [pointer の到着先] → 偽（右）へ
              ↓
           真（下）へ
```

到着先のブロックを 1 コーデルにしておくのがポイントです。DP が右なら右隣へ、下なら真下へ出ていくので、2 つの道の入り口がはっきり決まります。

### 2 つの数の大きいほうを出力する

例として、2 つの整数 a、b を読み、大きいほうを出力するプログラムを作ります。まずスタックの動きを設計しましょう。

```text
in(number)              [a]
duplicate               [a a]
in(number)              [a a b]
duplicate               [a a b b]
push 3, push 1, roll    [a b a b]   ← 並べ替え（第11章）
greater                 [a b c]     c = (a > b)
pointer                 [a b]       c = 1 なら下へ、0 なら右へ
```

`greater` で比較すると 2 つの値は消費されてしまうので、事前に a と b を複製しておきます。`push 3, push 1, roll` は `[a a b b]` を `[a b a b]` に並べ替える命令列です。`roll` の使い方は第11章で詳しく説明します。

分岐後は、次のように処理します。

- **a > b（下へ）**: `[a b]` の b を `pop` で捨て、`[a]` を出力する。
- **a ≤ b（右へ）**: `[a b]` の 2 つを入れ替えて a を `pop` で捨て、`[b]` を出力する。

そして、どちらの道も最後は**同じ場所に合流**して、`out(number)` と改行の出力を行います。

@piet ch09/max caption="2 つの整数の大きいほうを出力する（入力 3 と 8 → 出力 8）" input="3\n8\n"

@grid ch09/max

入力が 3 と 8 のときのトレースを見てみましょう。

@trace ch09/max input="3\n8\n"

左上の淡緑のコーデルはプログラムの開始位置です。そこから白を滑って淡赤のブロックに入り、命令の帯が始まります。開始位置と命令の帯を白で離しておくと、帯の最初のブロックを自由に選べます。

ステップ 10 の `pointer` では、`greater` の結果 0 が取り出されるので DP は右のままです。流れは右の白を滑って次の帯（入れ替えと `pop`）に入り、その後、白い通路を右 → 下 → 左と曲がって、下の段の淡青のブロックに右から入ります。

入力が 9 と 2 なら、`pointer` で 1 が取り出され、DP が下を向きます。

@trace ch09/max input="9\n2\n"

到着先の濃緑のコーデルの真下には緑のコーデルがあり、濃緑 → 緑の遷移で `pop` が実行されます。その後は白い縦の通路を下へ滑り、黒にぶつかって左に曲がり、同じ淡青のブロックに入ります。

Piet スタジオでこのプログラムを開き、`pointer` のブロックにブレークポイント（右クリック）を置いて実行すると、入力によって DP の向きが変わる瞬間を確認できます。入力欄の値を変えて試してみましょう。

### 合流の考え方

2 つの道を合流させるときは、**白を通って同じブロックに入る**ようにします。白を通った遷移では命令が実行されないので、直前のブロックの色が道によって違っていても問題になりません。上のプログラムでは、右の道は下の段の通路を左に進み、下の道は縦の通路から左に曲がって、同じ横の通路に乗ります。白い通路の交差と合流は、第8章で学んだ「滑走はまっすぐ進む」性質だけで実現できています。

合流したあとのスタックの状態が、どちらの道を通っても同じ形になっていることにも注意してください。上の例では、どちらの道も `[最大値]` という 1 要素のスタックで合流しています。スタックの形がそろっていないと、合流後の処理が道によって違う結果になってしまいます。

### 反時計回りの分岐

DP が右のときに 1 で `pointer` すると下へ曲がりますが、上へ曲がりたい場合は 3 を使います。条件 c（0 か 1）に 3 を掛けてから `pointer` すれば、真のときだけ反時計回りに曲がります。

```text
（条件 c を計算）      [c]
push 3, multiply       [3c]
pointer                c = 1 なら上へ、0 なら右へ
```

第17章で作る pasm は、条件付きジャンプをこの形に変換しています。上に曲がった道は、白の中で黒にぶつけて右に曲げれば（時計回り）、元の帯と平行に右へ進む通路になります。

## 9.4 switch による分岐

### ブロックの形で出口を選ぶ

`switch` で分岐するには、DP の方向の辺に複数のコーデルを持つブロックを用意します。たとえば縦に長いブロックなら、DP が右のとき、出口は右端の列のうち CC が左なら最も上、CC が右なら最も下のコーデルになります。

次のプログラムは整数を読み、偶数なら `E`、奇数なら `O` を出力します。

@piet ch09/evenodd caption="偶数なら E、奇数なら O を出力する（入力 7 → 出力 O）" input="7\n"

@grid ch09/evenodd

```text
in(number)          [n]
push 2, mod         [n mod 2]   0 または 1
switch              []          奇数なら CC が反転する
```

`switch` の到着先は、縦に 5 コーデル並んだ淡シアンのブロックです。CC が左のまま（偶数）なら最上段から、右に変わった（奇数）なら最下段から右へ出ていきます。それぞれの出口の先には白を挟んで、`E` と `O` を出力する帯を置いてあります。

@trace ch09/evenodd input="7\n"

上下の帯を 4 コーデル離しているのは、上の帯の停止用ブロックが下の帯と接しないようにするためです。

### pointer と switch の使い分け

`switch` は流れの向き（DP）を変えないので、2 つの道が同じ向きに平行して進みます。並んだ 2 本の帯を作りたいときに向いています。一方で、出口を変えるには特別な形のブロックが必要で、2 つの道の間隔もブロックの大きさで決まってしまいます。

`pointer` は流れの向きそのものを変えるので、道の配置の自由度が高く、3 方向以上への分岐も作れます（0、1、2、3 で右・下・左・上）。本書では主に `pointer` を使います。

!!! note "メモ"
    負の数の偶奇判定には注意が必要です。仕様どおりの処理系では −3 mod 2 は 1 ですが、npiet では −1 になり、さらに npiet の `switch` は負の値で CC を切り替えないため、−3 を「偶数」と判定してしまいます。

## 9.5 多方向の分岐と if-else

### 正・ゼロ・負

分岐を組み合わせれば、3 つ以上の場合分けもできます。入力した整数が正・ゼロ・負のどれかを表示するプログラムを、pasm で書いてみましょう。pasm の `jz L` は「先頭を取り出し、0 ならラベル L へジャンプ」、`jnz L` は「0 でなければジャンプ」です。

```pasm
; 入力した整数が正・ゼロ・負のどれかを表示する
  inn            ; [n]
  dup            ; [n n]
  jz zero        ; [n]
  push 0         ; [n 0]
  gt             ; [n>0]
  jnz positive
  prints "negative\n"
  halt
zero:
  prints "zero\n"
  halt
positive:
  prints "positive\n"
```

@piet ch09/sign caption="正・ゼロ・負を判定する（pasm で生成）" input="-7\n"

pasm は、`jz` や `jnz` を「`not` で 0/1 にそろえる → 3 を掛ける → `pointer`」という命令列に変換し、真のときに上へ出る道と偽のときに右へ出る道を、白い通路で目的の行まで配線します。生成された画像は手で描いたものより大きくなりますが、ジャンプ先をラベルで書けるので、複雑な分岐も間違えずに作れます。

### 絶対値

最後に、if-else の典型例として絶対値を計算するプログラムを見ておきます。

```pasm
; 絶対値: if (n < 0) n = 0 - n
  inn            ; [n]
  dup            ; [n n]
  push 0
  swap           ; [n 0 n]
  gt             ; [n 0>n]
  jz print       ; [n]
  push 0
  swap           ; [0 n]
  sub            ; [-n]
print:
  outn
  push 10
  outc
```

@piet ch09/abs caption="絶対値を出力する（入力 −15 → 出力 15）" input="-15\n"

`0 > n` を作るために、0 を n の下に潜り込ませています（`push 0` と `swap`）。`swap` は上 2 つを入れ替える pasm のマクロで、実際には `push 2, push 1, roll` に展開されます。条件が偽なら `print` へジャンプし、真なら 0 − n を計算してから `print` に進みます。このように、「条件が成り立たないときに飛び越す」形にすると、else 部分のない if 文を作れます。

## まとめ

- `not` は 0 を 1 に、それ以外を 0 にする。`greater` は「2 番目 > 先頭」なら 1。ほかの比較はこれらと `subtract` を組み合わせて作る。
- `pointer` は DP を時計回りに n 段階回す（負なら反時計回り）。`switch` は CC を |n| 回切り替える。
- 分岐の基本は「条件を 0/1 にする → `pointer` → 到着先の 1 コーデルから 2 方向に道を出す」。
- 分岐した道は、白を通って同じブロックに入ることで合流させる。合流時のスタックの形をそろえる。
- `switch` で分岐するには、出口の辺に複数のコーデルを持つブロックを用意する。
- 負の値を使う分岐は処理系による差が出やすいので、条件は 0 以上の値にそろえる。

## 練習問題

1. スタックが `[4 9]` のとき、`greater` を実行した結果を答えてください。また、`[4 9]` から「4 < 9」を表す 1 を得るにはどうすればよいですか。
2. DP が下を向いているときに、スタックの先頭が 3 の状態で `pointer` を実行すると、DP はどちらを向きますか。
3. 整数を 1 つ読み、0 なら `Z`、0 以外なら `N` を出力するプログラムを描いてください（`Z` は 90、`N` は 78）。
4. 2 つの整数を読み、等しければ `=` を、等しくなければ `!` を出力するプログラムを pasm で書いてください（`=` は 61、`!` は 33）。
5. 図「2 つの整数の大きいほうを出力する」を、小さいほうを出力するように変更してください。
