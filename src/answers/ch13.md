## 第13章 文字と文字列

### 問題 13-1

大文字への変換の逆です。範囲を `A`（65）〜`Z`（90）に変え、32 を引くかわりに足します。


```pasm
; 英大文字を小文字に変換する（EOF まで）
loop:
        push 0
        inc
        dup
        jz eof
        swap
        pop             ; [c]
        dup
        push 64
        gt              ; [c (c>64)]
        pick 1
        push 91
        swap
        gt              ; [c (c>64) (91>c)]
        mul             ; [c f]
        push 32
        mul
        add             ; [c+32f]
        outc
        jmp loop
eof:
        halt
```

### 問題 13-2

`0`〜`9` は文字コード 48〜57 です。`(c > 47) かつ (58 > c)` が 1 なら出力し、0 なら捨てます。ここでは捨てる処理があるので、計算ではなく分岐を使っています。


```pasm
; 入力から数字の文字だけを取り出して出力する
loop:
        push 0
        inc
        dup
        jz eof
        swap
        pop             ; [c]
        dup
        push 47
        gt              ; [c (c>47)]
        pick 1
        push 58
        swap
        gt              ; [c (c>47) (58>c)]
        mul             ; [c f]
        jnz digit
        pop             ; 数字以外は捨てる
        jmp loop
digit:
        outc
        jmp loop
eof:
        push 10
        outc
```

### 問題 13-3

2 進数のプログラムの 2 を 8 に変えます。8 進数の桁は 0〜7 なので、番兵には桁として現れない 8 を使えます（負の数など、桁にならない値なら何でもかまいません）。


```pasm
; 整数を 8 進数で出力する
        inn             ; [n]
        push 8
        swap            ; [8 n]          8 は番兵（桁は 0〜7）
loop:
        dup
        push 8
        mod             ; [8 .. n d]
        swap
        push 8
        div             ; [8 .. d n/8]
        dup
        jnz loop
        pop
print:
        dup
        push 8
        sub
        jz done
        outn
        jmp print
done:
        push 10
        outc
```

### 問題 13-4

番兵を、文字コードとして現れることのない値、たとえば -1 にします。EOF の判定は「先頭が -1 か」なので、`push 1` `add` してから `jz` で調べます。入力をそのまま出力する `cat` に応用すると次のようになります。


```pasm
; NUL 文字も通す cat（番兵に -1 を使う）
loop:
        push -1         ; [-1]           どの文字コードとも重ならない番兵
        inc             ; [-1 c] または [-1]
        dup
        push 1
        add             ; [.. top+1]
        jz eof          ; 先頭が -1 なら EOF
        swap
        pop             ; [c]
        outc
        jmp loop
eof:
        halt
```

@piet ch13/ex4 caption="練習問題 4 の解答。NUL 文字も通す cat"

`a`、NUL、`b`、改行、`Piet`、改行という入力を、NUL を含めてそのまま出力することを、piet.py と npiet の両方で確かめてあります。pasm の `push -1` は `push 1` `push 2` `subtract` に展開されるので、番兵が 0 のときより数コーデル大きくなります。

npiet の `in(char)` は、読んだバイトを `c % 0xff`（255 で割った余り）にしてから積みます。そのため、値が 255 のバイトは 0 として読まれてしまいます。ASCII のテキストには 255 は現れないので問題になりませんが、バイナリのデータを扱うときには注意が必要です（付録C）。いずれにしても、npiet の `in(char)` が負の値を積むことはないので、番兵 -1 は npiet でも正しく働きます。

### 問題 13-5

自由解答です。13.1 節の測定から、どの方法でも「文字コードを作る」部分が大部分を占めることがわかっています。考えられる工夫の例を挙げます。


- 差分の方法を基本にして、差が大きいところ（`,` や空白の前後）だけ文字コードを直接作る
- `l` と `o` のように何度も現れる文字は、最初に作った値を `duplicate` で取っておいて再利用する
- pasm を使わずに手で描き、行の折り返しや配線のぶんの余白をなくす（第15章）

工夫したら、本書の `tools/samples.py` のように出力が変わっていないことを必ず確かめてから、大きさを比べましょう。
